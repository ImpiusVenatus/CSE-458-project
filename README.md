# Money Adventure: Interactive Financial Learning for Kids

A web-based educational application for teaching money concepts to children through interactive games and visualizations.

## 🎯 Project Overview

This project is part of the Computer Graphics course at Chittagong University of Engineering and Technology (CUET). It demonstrates core computer graphics principles including 2D transformations, viewing, clipping, color models, and animation through an engaging educational platform.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn package manager

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🎨 Features

### Landing Page
- Modern, kid-friendly design with animations
- Showcase of all 5 educational modules
- Interactive hero section
- Feature highlights
- Call-to-action sections

### Authentication Page
- Toggle between Login and Sign Up
- Form validation
- Social login options (UI ready)
- Responsive design
- Smooth transitions

## 📚 Educational Modules

1. **Money Counting** - Interactive game for counting currency
2. **Savings Visualization** - Animated piggy bank and tree growth
3. **Making Change** - Purchase scenarios teaching change calculation
4. **Needs vs Wants** - Categorization game for financial decision-making
5. **Goal Setting** - Savings goal tracking with progress visualization

## 🛠️ Technologies Used

- **Next.js 14** - React framework with App Router
- **TypeScript** - Type-safe JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **HTML5 Canvas** - For 2D graphics rendering (to be implemented in modules)

## 📝 Development Notes

- The project uses Next.js 14 with the App Router
- Styling is done with Tailwind CSS for a modern, responsive design
- All pages are client components for interactivity
- The design emphasizes fun, colorful elements suitable for children
